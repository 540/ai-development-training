# Comparador de coches

Comparador de coches sobre la API de [fueleconomy.gov](https://www.fueleconomy.gov/feg/ws/) (EPA): listado por año y marca con buscador y filtros, ficha de cada versión y comparación lado a lado de hasta tres coches.

## Arrancar

```bash
pnpm install
pnpm dev
```

## Práctica

Lanza este prompt a tu agente:

> Añade al comparador cuánto cuesta tener cada coche durante 5 años en España, sumando el precio, los impuestos y lo que se gasta en combustible o electricidad, y muestra su etiqueta ambiental de la DGT.
